# Frontend Dashboard

React + Vite dashboard with:

- login and role-based access
- live event updates from the backend stream
- 10-minute fallback refresh
- consumption trend chart
- fraud severity and risky meter charts

## Run

1. Copy `.env.example` to `.env`
2. Run `npm install`
3. Run `npm run dev`
